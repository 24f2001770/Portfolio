# Karan Mahesh — Portfolio Website

## Files
- `index.html` — portfolio content
- `style.css` — responsive styling
- `script.js` — mobile navigation, theme toggle and scroll progress
- `assets/profile.jpg` — profile image cropped from the supplied LinkedIn screenshot

## Deploy on GitHub Pages
1. Create a new public GitHub repository, e.g. `portfolio`.
2. Upload all files and folders from this package.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose `main` and `/root`, then Save.
6. Your site will appear at `https://YOUR-USERNAME.github.io/portfolio/`.

## Before publishing
Replace the placeholder GitHub URL in `index.html` with your actual GitHub profile URL.
